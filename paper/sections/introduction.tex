\section{Introduction}

A battery retired from an electric vehicle (EV) can often still serve as stationary storage, but only if its state of health (SOH) can be judged reliably. Machine-learning SOH models exist~\cite{ref1,ref2,ref3,ref4}, yet retired batteries differ in chemistry, maker, usage and temperature, so a model trained once may fail on the next group. Continual learning updates the model with each new group while keeping what it learned before.

We \emph{forecast} SOH one to six capacity checks ahead, because a reuse decision depends on how a battery will age and because estimating today's SOH from cycling data lost to simply repeating the last measurement on our first dataset (\S\ref{sec:methods}). The forecast is sorted into capacity-based reuse classes (Fig.~\ref{fig:system}).
