\section{The Residual TFT-EWC Approach}

\subsection{Data}
\label{sec:data}

Six public CC~BY~4.0 datasets are used (Table~\ref{tab:data}); our parsing reproduces the published S1 reference performance test (RPT) capacities and all 843 S6 check capacities exactly. Estimating the current SOH on S1 lost to persistence (gradient boosting 1.78~pp, persistence 0.99~pp), because cycle features barely track health (median within-cell $|\rho|=0.09$); we therefore forecast, with the protocol fixed before any forecaster was fitted. Apache Spark condenses the S6 ageing cycles (132~GB, $9.0\times10^{8}$ rows) into 21 block inputs.

\subsection{Target, inputs and protocols}
\label{sec:soh}
\label{sec:task}
\label{sec:features}
\label{sec:protocols}

For cell $b$ with check capacities $C_{b,k}$ in time order~\cite{ref6,birkl2017},
\begin{equation}
  \begin{aligned}
    \mathrm{SOH}_{b,k} &= 100\,C_{b,k}/C_{b,1}\;\%,\\
    \Delta_{b,k,h} &= \mathrm{SOH}_{b,k+h} - \mathrm{SOH}_{b,k},
  \end{aligned}
  \label{eq:soh}
\end{equation}
so SOH is relative to the first valid check, and a forecast from origin $k$ predicts the change $\Delta$ over $h$ checks ($h{=}1$--3, E1; $h{=}1$--6, E2)~\cite{lim2021tft}. Errors are root-mean-square errors (RMSE) in percentage points (pp). Inputs use only what is known at the origin: SOH history, the fade rate $r_{b,k}$ (least-squares slope over the last three checks~\cite{hastie2009elements}), fixed descriptors, the planned usage until the target, and optional diagnostics (F1). Each cell's checks are cut at 60\% and 80\% into purged train, validation and test periods.

\textbf{Protocols.} \textbf{P1}, continual stream: one task per S1 cell or S6 condition, 10 task orders $\times$ 5 seeds. \textbf{P2}, unseen group: one cell or condition held out. \textbf{P3}: first-life pretraining on S7--S9, then the S6 stream.

\subsection{Model}
\label{sec:backbones}

The Temporal Fusion Transformer (TFT)~\cite{lim2021tft} sees the four latest origins of a cell (Fig.~\ref{fig:arch}; 12{,}708 parameters). It learns a correction $g_\theta$ to linear extrapolation $\hat\Delta^{\mathrm{lin}}_{b,k,h} = r_{b,k}(t_{b,k+h}-t_{b,k})$, a residual hybrid~\cite{zhang2003hybrid}:
\begin{equation}
  \hat\Delta_{b,k,h} = \hat\Delta^{\mathrm{lin}}_{b,k,h} + \alpha_h\, g_\theta(\mathbf{x}_{b,k,h}),
  \label{eq:residual}
\end{equation}
where $\alpha_h\in[0,1]$ shrinks the correction (least-squares slope on calibration rows). After each task $j$, Elastic Weight Consolidation (EWC)~\cite{kirkpatrick2017ewc} adds
\begin{equation}
  \tfrac{\lambda}{2}\textstyle\sum_{p} F_{j,p}\,(\theta_p - \theta^{*}_{j,p})^2
  \label{eq:ewc}
\end{equation}
with the diagonal Fisher information $F_j$. Split-conformal intervals~\cite{lei2018conformal} take the calibration-error quantile per horizon.


\textbf{Comparators.} Persistence ($\hat\Delta=0$)~\cite{hyndman2006}, linear extrapolation, ridge, histogram gradient boosting (GB)~\cite{friedman2001}, a multilayer perceptron (MLP), fine-tuning, replay~\cite{rolnick2019replay} and joint training. GB is run with all earlier conditions stored (GB-ALL) and, under our no-storage rule, refitted on the latest condition (GB-LAST). V2 (post hoc) swaps EWC for replay of 40 rows per condition, a three-model ensemble and calibration before training.

\subsection{Metrics and statistics}
\label{sec:tuning}
\label{sec:metrics}

From the error matrix $R_{i,j}$ (task $j$ after step $i$)~\cite{lopezpaz2017gem} we report final average error (retention), error on the newest task (adaptation) and forgetting~\cite{chaudhry2018rwalk}; intervals by coverage and interval score~\cite{gneiting2007scoring}; reuse classes C0 $>$95, C1 90--95, C2 80--90, C3 $\le$80\%. Every follow-up was registered before it ran (supplement Table~SXII). A difference counts as ``replicated'' only if a Wilcoxon test~\cite{wilcoxon1945} with Holm correction~\cite{holm1979} is significant in both seed sets (0--4, 5--9), with the same sign and $|d|\ge0.05$~pp; below 0.05~pp in both it is ``equivalent''.
