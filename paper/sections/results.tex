\subsection{Data and diagnostic features}
\label{sec:res-data}

\emph{S1 diagnostics.} The diagnostic features track the current SOH closely within each cell (Fig.~\ref{fig:ic}):
\begin{itemize}
  \item the height of the incremental-capacity peak near 4.07~V falls smoothly with ageing (median within-cell Spearman $\rho=0.97$ with SOH, same sign in all six cells);
  \item pulse and EIS resistances rise ($|\rho|$ between 0.83 and 0.94).
\end{itemize}

Their association with the SOH change \emph{to the next RPT}, which a forecaster must predict beyond persistence, is weak (median $|\rho|\le0.3$ for most features). The exceptions are at the low-voltage end:
\begin{itemize}
  \item the low-frequency real impedance at 3.26~V, with $\rho\approx0.43$ and the same sign in all six cells;
  \item the charge between 3.63 and 3.26~V, with $\rho=-0.52$ and the same sign in five cells.
\end{itemize}
These features also alternate from RPT to RPT with the 20/35~$^\circ$C cycling blocks, so part of this association may reflect the temperature schedule rather than ageing.

\emph{S6.} The seven usage conditions produce clearly different fade (Fig.~\ref{fig:s6soh}). The 100\% depth-of-discharge case fades fastest, and the 2C-discharge case fades slowest per cycle. All cells cross from C0 to C3 during the test, so the reuse classes are populated. This contrasts with S1, where every sample stays in C0.

\subsection{Continual stream (P1)}
\label{sec:res-p1}

Table~\ref{tab:p1} gives the final average test error, skill and forgetting of every method on both datasets. Table~\ref{tab:horizon} breaks the error down by horizon, and Table~\ref{tab:tests} gives the paired comparisons with TFT\,+\,EWC.

\emph{S1.}
\begin{itemize}
  \item \emph{Proposed model:} TFT\,+\,EWC reaches a final average RMSE of 0.462~pp, a skill of 0.27 relative to persistence (0.632~pp). It is significantly better than persistence, linear extrapolation, ridge regression on F0 and F1, and MLP fine-tuning and MLP\,+\,EWC.
  \item \emph{Level with it:} gradient boosting (0.466~pp), TFT fine-tuning (0.467~pp) and MLP replay (0.475~pp).
  \item \emph{Better than it:} a ridge regression on the planned usage alone, i.e. the days at each temperature set point and at rest (0.450~pp). Its advantage is 0.012~pp (95\% CI 0.007--0.017).
  \item \emph{Forgetting} is small for every method (0.016--0.040~pp), and TFT\,+\,EWC does not differ significantly from TFT fine-tuning in error or forgetting.
  \item \emph{Diagnostic features} improve TFT\,+\,EWC by 0.009~pp (CI 0.001--0.017), which is not significant after Holm correction ($p_{\mathrm{Holm}}=0.083$).
  \item \emph{By horizon,} persistence and linear extrapolation degrade quickly (0.83 and 0.90~pp at $h{=}3$), while the learned models stay between 0.42 and 0.49~pp.
\end{itemize}

\emph{S6.} The picture changes when tasks differ in usage.
\begin{itemize}
  \item \emph{Forgetting is substantial:} 0.18--0.46~pp, an order of magnitude larger than on S1.
  \item \todo{The significance statements in this item and in the F0 item below did not reproduce in a re-run (EWC strength selected as 1000 instead of 100; see docs/RESULTS.md, Reproducibility check). Rewrite after the reportable re-run.} \emph{EWC matters for the TFT:} TFT\,+\,EWC (0.677~pp) is on average 0.206~pp better than TFT fine-tuning (0.883~pp; CI 0.091--0.338, $p_{\mathrm{Holm}}=0.005$, rank-biserial 0.52). The median paired difference is 0.062~pp, so the mean is driven partly by unstable fine-tuning runs. TFT\,+\,EWC also forgets 0.187~pp less on average (median 0.075~pp), but this is not significant after Holm correction ($p_{\mathrm{Holm}}=0.0503$).
  \item \emph{But TFT\,+\,EWC is not the most accurate method:}
  \begin{itemize}
    \item MLP fine-tuning (0.531~pp) and MLP\,+\,EWC (0.540~pp) are significantly better;
    \item the joint upper bounds (MLP 0.414, TFT 0.427~pp) are better still, so the continual-learning cost is about 0.25~pp for the TFT;
    \item linear extrapolation of the recent fade rate (0.343~pp) and gradient boosting on F1 (0.372~pp) are the best forecasters overall.
  \end{itemize}
  \item \emph{Instability:} the TFT results vary strongly with the task order (s.d.\ 0.26~pp over runs for TFT\,+\,EWC, 0.54~pp for TFT fine-tuning).
  \item \emph{Diagnostic features:} without them (F0), TFT\,+\,EWC reaches 0.621~pp and forgets significantly less. The diagnostic features do not help the TFT on S6.
  \item \emph{Reuse classes:} every S6 test period lies in class C3, so class agreement in P1 is trivially perfect for all methods and is not informative.
\end{itemize}

\subsection{Unseen cell or usage condition (P2)}
\label{sec:res-p2}

Table~\ref{tab:p2} gives the leave-one-group-out results.
\begin{itemize}
  \item \emph{S1 (unseen cell):} gradient boosting on F1 is best (0.219~pp). The MLP (0.285~pp), the TFT (0.292~pp) and the usage-only ridge regression (0.301~pp) are close, and persistence reaches 0.545~pp.
  \item \emph{S6 (unseen usage condition):} gradient boosting is again best (0.710~pp), ahead of the MLP (0.821~pp), ridge regression on F0 (0.859~pp) and the TFT (0.868~pp); persistence reaches 2.817~pp.
  \begin{itemize}
    \item The 100\% depth-of-discharge condition is the hardest for every method (1.8--2.4~pp).
    \item The forecast reuse class agrees with the measured class for 95--97\% of samples with the learned models (macro-F1 0.83--0.88), against 85\% (0.64) for persistence.
  \end{itemize}
  \item \emph{Significance:} with six or seven held-out groups, no difference with the TFT survives Holm correction in either dataset.
\end{itemize}

\subsection{Reproducibility of the comparisons}
\label{sec:res-repro}

Both forecasting notebooks were re-run in a pinned environment (Python 3.11.15, numpy 2.4.6, pandas 3.0.6, scikit-learn 1.9.1, torch 2.14.1) on data rebuilt from the raw archives and verified file by file against recorded checksums. The torch version of the first run was not recorded.
\begin{itemize}
  \item \emph{Reproduced:} every baseline result, both joint upper bounds, every P2 result and the ranking of methods; the neural models move by at most 0.002~pp on S1, 0.006~pp in S6 P2 and 0.059~pp in S6 P1 (TFT\,+\,EWC: 0.677 to 0.704~pp).
  \item \emph{Not reproduced on S1:} five Holm-corrected comparisons with TFT\,+\,EWC cross $p=0.05$. Their differences (0.005--0.014~pp) are an order of magnitude smaller than the shift the label definition alone causes (up to 0.089~pp).
  \item \emph{Not reproduced on S6:} validation tuning selected EWC $\lambda=1000$ instead of 100 (a 0.008~pp tie over three tuning runs). The advantage of TFT\,+\,EWC over TFT fine-tuning then changes from $p_{\mathrm{Holm}}=0.005$ to 0.060, while its reduction of forgetting changes from 0.050 to 0.008.
\end{itemize}
We therefore report S1 method differences as practically equivalent and do not claim that EWC significantly helps the TFT on S6. The protocol below adds 10 tuning runs per grid value, a one-standard-error selection rule and a replication rule.

\subsection{First-life pretraining (P3)}
\label{sec:res-p3}

The first-life pool comprises 369 cells (S7--S9) and 36{,}711 forecasting samples, against 2{,}409 in S6. Validation tuning selected learning rates of $3\times10^{-4}$ (MLP) and $3\times10^{-3}$ (TFT), and EWC strengths of 1000 (MLP) and 0.01 (TFT): \emph{for the pretrained TFT, validation selects almost no EWC}. Fig.~\ref{fig:p3} shows the final average error on S6 for main seeds 0--4 and replicate seeds 5--9.

\begin{figure}[t]
  \centering
  \includegraphics[width=\columnwidth]{figures/d21_p3_final_error.png}
  \caption{P3: final average test RMSE on S6, mean and 95\% bootstrap CI over 50 runs (10 orders $\times$ 5 seeds) for the main and replicate seed sets. Dashed lines: linear extrapolation and gradient boosting fitted on the S6 training data.}
  \label{fig:p3}
\end{figure}

Applying the replication rule (significant after Holm correction in both seed sets, same sign, at least 0.05~pp in both) to the comparisons with pretrained TFT\,+\,EWC:
\begin{itemize}
  \item \emph{EWC versus fine-tuning on the pretrained TFT:} practically equivalent in final error, forgetting and backward transfer (differences of 0.015--0.017~pp in both seed sets).
  \item \emph{Pretrained TFT\,+\,EWC versus pretrained MLP fine-tuning:} TFT\,+\,EWC is better, replicated in final error (by 0.334 and 0.185~pp), forgetting and backward transfer.
  \item \emph{Pretraining versus training from scratch:} both backbones are better from scratch on average (TFT 0.401/0.415~pp from scratch against 0.509/0.591~pp pretrained with EWC); for the TFT the difference is significant only in the replicate set, so it is not replicated.
  \item \emph{Baselines:} linear extrapolation (0.343~pp) remains the most accurate method on S6; the TFT from scratch is below gradient boosting (0.451~pp) on average.
\end{itemize}
The S6 stream does not degrade the pretrained models' error on the pool's test split (TFT\,+\,EWC: 3.280 to 3.148~pp, main seeds; Fig.~\ref{fig:retention}). On that split, however, the pretrained models are less accurate than linear extrapolation (3.001~pp): with the shared inputs, pretraining does not learn a first-life model that transfers.

\begin{figure}[t]
  \centering
  \includegraphics[width=\columnwidth]{figures/d21_p3_pool_retention.png}
  \caption{Error of the pretrained models on the pool's test split before and after the S6 stream (mean of 50 runs per seed set). Dashed lines: persistence and linear extrapolation on the same split.}
  \label{fig:retention}
\end{figure}

A post hoc ablation (one seed set; Fig.~\ref{fig:ablation}) explains why the TFT trained from scratch improves from 0.891~pp with the D20 inputs to 0.401~pp with the shared inputs. Dropping the 17 diagnostic features lowers the error by 0.23--0.35~pp, and the calendar time between checks lowers it by 0.22--0.31~pp (both $p_{\mathrm{Holm}}<0.001$ at both learning rates); the learning rate has no significant effect. This agrees with the observation that fade per cycle in S6 rises with the calendar time between checks at 50~$^\circ$C.

\begin{figure}[t]
  \centering
  \includegraphics[width=\columnwidth]{figures/d21_ablation_a1.png}
  \caption{Post hoc ablation of the TFT trained from scratch on S6: final average test RMSE (mean of 50 runs) for four input sets and two learning rates.}
  \label{fig:ablation}
\end{figure}

\emph{Computational cost.} On one CPU thread, pretraining on the pool takes 22~s for the MLP and 251~s for the TFT on average (10 seeds). Learning the whole S6 stream then takes 1.0--3.0~s for the MLP variants and 15~s (fine-tuning) to 23~s (EWC) for the TFT; EWC adds about 50\% to the TFT's training time through the Fisher-information computation, without improving its accuracy.

\subsection{What the TFT uses}
\label{sec:res-interp}

For the TFT trained from scratch on S6 (5 seeds), the variable-selection weights averaged over the test periods rank the time to the target (0.26) and the recent fade rate (0.08) highest, but the top-ranked input differs between seeds, and inputs that are constant within S6 (chemistry, calendar ageing) receive non-negligible weight (Fig.~\ref{fig:weights}). Attention over the four previous origins is nearly uniform (0.24--0.26 per lag). The weights are therefore not a reliable measure of importance on these data, and the TFT makes little use of its history window.

\subsection{Summary of findings}
\label{sec:res-summary}

\begin{enumerate}
  \item The best learned forecasters clearly beat persistence: skill up to 0.29 on S1 and 0.79 on S6. Not every model does, though; on S1, ridge regression on F0 and linear extrapolation are worse than persistence.
  \item Which information matters differs between the datasets. On S1, where fade is small and driven by the test schedule, the planned usage alone is the strongest predictor. On S6, where fade is large and smooth, the recent fade rate is.
  \item Forgetting depends on how different the tasks are. It is negligible across the six homogeneous S1 cells and substantial across the seven S6 usage conditions. Whether EWC significantly helps the TFT there depends on the run (Section~\ref{sec:res-repro}); after first-life pretraining, EWC and fine-tuning are practically equivalent for the TFT (Section~\ref{sec:res-p3}).
  \item The proposed TFT\,+\,EWC is not the most accurate forecaster on either dataset. It is level with gradient boosting and TFT fine-tuning on S1, and behind the MLP continual methods, gradient boosting and linear extrapolation on S6.
  \item Pretraining on 369 first-life cells of three other chemistries does not improve the S6 forecasts and does not make EWC useful for the TFT; linear extrapolation of the recent fade rate remains the most accurate method on S6.
\end{enumerate}
